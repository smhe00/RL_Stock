# Validation reports

Store independent validation evidence for standalone WebGPT Wake Bridge release candidates here.

Each report must record the exact candidate commit, commands, test results, blank demo repository HEAD, E2E handoff ID, marker evidence, environment versions, and final recommendation (`ACCEPT_1_0_0` or `REVISIONS_REQUIRED`).

Validation is test-only. If a defect is found, report it and stop rather than editing the candidate in the validation session.
