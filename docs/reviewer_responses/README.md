# Reviewer Responses

This directory is the canonical location for ChatGPT Reviewer outputs.

## Ownership

```text
docs/review_packets/      Claude-owned review submissions / Gate packets
docs/reviewer_responses/  ChatGPT Reviewer responses
docs/agent_state/         Claude-owned machine-readable state
docs/reviewer_state/      ChatGPT-owned machine-readable state
```

Historical Reviewer Responses from Gate 0 through early Gate 4 were migrated here on 2026-08-09. Their file contents/blobs are preserved; only their repository paths changed.

New Reviewer Responses must not be written to `docs/review_packets/`.
